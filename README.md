# SENSIEDEV Portfolio

3D portfolio for **Briel Jarren Fronda** — web developer, systems programmer, and college instructor.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/SensieDev/sensiedev-portfolio)

## Live demo

After deploying on Render, your site will be available at:

`https://sensiedev-portfolio.onrender.com`

(Render may assign a slightly different subdomain — check your Render dashboard.)

## Stack

- HTML, CSS, JavaScript
- Three.js (CDN) for the hero 3D scene
- CSS 3D transforms for project icons

## Local preview

```bash
npx serve -l 5173
```

Open http://localhost:5173

## Deploy on Render (manual)

1. Go to [Render Dashboard](https://dashboard.render.com)
2. **New → Blueprint**
3. Connect **SensieDev/sensiedev-portfolio**
4. Click **Deploy Blueprint**

Or use the **Deploy to Render** button above.
